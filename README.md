# alarifi.group

The website for Alarifi Group, published with GitHub Pages at https://alarifi.group.

| Path | Page |
|---|---|
| `/` | Home (English, with an Arabic toggle) |
| `/reddot/` | Red Dot: Cat Laser Chase |
| `/reddot/support` | Red Dot support |
| `/reddot/privacy` | Red Dot privacy policy |
| `/app-ads.txt` | AdMob authorized seller line |

Plain HTML, CSS and JavaScript with no build step. Each page holds both languages side by side (`data-when="en"` and `data-when="ar"`); `assets/site.js` switches between them and between the light and dark themes.

The Alexandria font is self-hosted under the SIL Open Font License (`assets/OFL.txt`).
